# React E-Commerce

A responsive e-commerce web application built with React and TypeScript, featuring a customer storefront and an admin dashboard for product and category management.

## 🚀 Live Demo

[View Live Demo](https://koki-store-gamma.vercel.app/)

## ✨ Features

* User authentication and protected routes
* Product listing and product details
* Product and category CRUD operations
* Admin dashboard
* Shopping cart and checkout flow
* Form validation with Zod
* State management with Zustand
* Server-state management with TanStack Query
* Responsive UI

## 🛠️ Tech Stack

* React 19
* TypeScript
* Vite
* React Router
* TanStack Query
* TanStack Form
* Zustand
* Zod
* Tailwind CSS

## ⚙️ Getting Started

### Installation

```bash
git clone https://github.com/walaaosamamoh/Koki-Store.git
cd Koki-Store
npm install
```

### Development

```bash
npm run dev
```

### Production Build

```bash
npm run build
```
